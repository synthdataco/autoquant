# Suggestions

1. **Disk Space Constraint**: The workspace encountered severe disk space limitations when running `uv sync` out of the box because `torch` (and its heavy CUDA dependencies like `nvidia-cudnn-cu13`) completely exhausted the 1.5GB of available overlay filesystem. We worked around this by setting `UV_CACHE_DIR` to the workspace directory and specifically pulling CPU PyTorch, but this requires an environment or documentation adjustment for miners expecting to use the GPU easily out-of-the-box.
2. **Missing Realized Paths**: In the backtester, when fetching `market_data/realized/...` paths for backtesting assets like `AAPLX` over certain dates, `synth_lib` attempts to lazily prefetch and write them to the snapshot directory. Because the directory is mounted read-only, it crashes. Pre-computing all realized paths in the snapshot or redirecting `RealizedPathStore` writes to the writable `miner_outputs` directory would prevent these crashes for miners running extensive local backtests.
